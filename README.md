# Corner Bean Café: sample website

A responsive one-page website for a fictional café, built as a portfolio sample for small local businesses.

**Live site:** https://cornerbeancafe.netlify.app/

> This is a sample project. The business, address, phone number and prices are made up.

## What it includes

- Hero section with a clear call to action
- "Popular today" strip and a three-group menu with prices
- About section, contact details with a click-to-call link and a Google Maps link
- Opening hours in an accessible table

## Built with

- HTML and CSS only, with no frameworks or JavaScript for the layout
- CSS custom properties (variables) so the colours and fonts can be changed in one place
- Flexbox and grid for layout, with one breakpoint for phones
- Google Fonts (Fraunces and Source Sans 3)
- Hosted on Netlify, deployed from this repo

## Quality checks

- Tested at 375px, 768px and desktop widths
- Lighthouse on the live site (mobile): Performance 99, Accessibility 100, Best Practices 100, SEO 100
- Images compressed and given alt text

## Run it locally

Download or clone the repo and open `index.html` in a browser. There is nothing to install or build.
